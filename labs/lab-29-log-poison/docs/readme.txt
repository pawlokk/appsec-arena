DocViewer Internal Documentation
==================================

Version: 1.0.0
Last Updated: 2024-01-15

This system provides read-only access to internal documentation files.
All files are served relative to the application root directory.

Usage:
  GET /view?file=<relative_path>

Examples:
  /view?file=docs/readme.txt
  /view?file=docs/changelog.txt

For support, contact the internal IT team.
